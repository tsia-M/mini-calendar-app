Mini Calendar

A simple web application that displays the current date dynamically using JavaScript.

Technologies:
- HTML
- CSS
- JavaScript

Features:
- Displays current day, date, month, and year
- Responsive design for smaller screens
- Clean centered UI

How it works:
The app uses JavaScript’s Date object to retrieve the current date and updates the DOM dynamically.
